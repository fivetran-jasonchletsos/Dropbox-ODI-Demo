# Sentinel

US Bank Risk Watch — the customer-facing surface of the Dropbox ODI demo.

A CDO inherits a shared drive with 583 files. Fivetran picks them up, **dbt labs** conforms them on the bronze → silver and silver → gold edges, and Sentinel is the gold-layer dashboard.

## Quickstart

```bash
npm install
npm run dev
# open http://localhost:5173
```

## Scripts

- `npm run dev` — Vite dev server with HMR
- `npm run build` — production build (typecheck + vite build)
- `npm run preview` — preview the built bundle
- `npm run data:generate` — regenerate the synthetic JSON data

## Architecture

- **Vite + React 18 + TypeScript** with React Router v6 and Recharts
- **Tailwind CSS v4** via `@tailwindcss/vite` (no `tailwind.config.js`; uses `@import "tailwindcss"` and `@theme`)
- **Static JSON** under `public/data/`, regeneratable from `public/data/_generate.mjs` (pure ESM, no dependencies)

## Pages

| Route                       | Page                  |
| --------------------------- | --------------------- |
| `/`                         | Overview              |
| `/institutions`             | Institutions table    |
| `/institutions/:certId`     | Institution detail    |
| `/states`                   | State risk hex map    |
| `/catalog`                  | 583-file inventory    |
| `/pipeline`                 | Bronze · Silver · Gold|
| `/architecture`             | ODI lineage & engines |
| `/watchlist`                | localStorage watchlist|
| `/about`                    | Tech, sources, credit |

## Data

FDIC public datasets (Failed Bank List, Summary of Deposits, Institutions). Risk scores, AI summaries, and quarterly trends are synthetic — generated by a deterministic PRNG so the demo is fully reproducible.
